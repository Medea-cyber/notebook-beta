# 📓 Блокнот рассказчика — бета

Тестовая версия «Блокнота рассказчика». Здесь сначала появляются новые функции, прежде чем попасть в основную версию.

Сейчас в бете: картинка с образами в гардеробе. Перед важной сценой генератор рисует один лист, где персонаж показан во всех предложенных нарядах рядом, и выбирать становится нагляднее.

## Как пользоваться

1. Установите по ссылке на этот репозиторий: **Расширения → Install extension**.
2. В **Manage extensions** выключите обычный «Блокнот рассказчика» и перезагрузите страницу. Обе версии сразу работать не будут: бета предупредит и не запустится.
3. Для картинок подключите генерацию изображений в Таверне: **Расширения → Image Generation**, выберите источник (например, Pollinations).

Записи блокнота общие у обеих версий. Вернуться к обычной можно в любой момент: выключите бету, включите основную и перезагрузите страницу.

Если генерация картинок не подключена, гардероб работает как обычно, только по текстовым описаниям. Картинку можно отключить галочкой в настройках блокнота.
